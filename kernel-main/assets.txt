# Asset archive manifest: what "boot install" / "boot repair" put on disk.
#
# build-assets.sh turns this into bin/assets.tar (ustar), build-bootloader.sh
# writes that behind the kernel in the boot area, stage 2 loads it with the
# kernel and the boot command extracts it. Adding a file is one line here;
# the kernel does not change.
#
#   <path under home>                <source, relative to this file>          [mode]
#
# mode is octal: 755 for programs (executable on disk), 644 for data.
# A path ending in '/' with no source is an empty folder.
#
#   <folder>/                        policy=<user|admin|system|network> [write=<policy>]
#
# puts the folder and everything in it in that group policy, with the
# policy's permissions as their security mask, on "boot install" and on
# every "boot repair" (a policy changed by hand inside it is set back).
# write=<policy> lets only programs holding that policy's permissions
# change it (write, create, delete, rename, move, permissions); without
# it, writing needs what reading needs.
# A folder inside it can name its own. Without a line, new files and
# folders take their folder's policy, or "user" when it has none.
#
# Fonts and images go in as the files they are: no conversion step. The dwm
# finds fonts in sys/fonts by their header and decodes the PNGs in
# sys/images itself (libc os/image.h); a file's name without its extension
# is the name the code asks for ("sys/images/icon_folder.png" is
# "icon_folder", "sys/fonts/opensans.ttf" is "opensans").
